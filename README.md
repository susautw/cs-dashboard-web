# CS Dashboard Web

A browser-based dashboard for viewing container scanning JSON reports.

Live demo: https://susautw.github.io/cs-dashboard-web/

## Features

- Open a local folder directly in Chrome with `window.showDirectoryPicker()`
- Recursively scan for `.json` report files
- Select one or more reports from the sidebar
- View aggregated severity stats and per-file vulnerability tables
- Open a detail panel for each vulnerability

## Supported Format

Current supported format:

- `gl-container-scanning-report.json` generated by Trivy with `@/contrib/gitlab.tpl`

## Development

Install dependencies:

```bash
bun install
```

Start the dev server:

```bash
bun run dev
```

Build for production:

```bash
bun run build
```

## Notes

- Use Chrome or Edge for the best compatibility.
